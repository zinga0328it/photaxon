# photaxon
FiberSpider by Photaxon — decentralized FTTH R&amp;D laboratory for intelligent distributed cabinets, LLM agents, OpenStack, autonomous provisioning, telemetry and resilient network control.

## RAGNO Role

This branch contains the PC RAGNO laboratory configuration and FiberSpider components for public sharing.

- FiberSpider laboratory node implementation
- OpenStack / Neutron laboratory integration
- Modular cabinet simulation for CAB-A, CAB-B, CAB-C
- FiberSpider agent runtime and provisioning workflow
- FastAPI laboratory backend for activation and verification
- Technician authentication with Telegram OTP workflow
- FTTH provisioning remains at laboratory / simulation level
- Physical GPON / OLT hardware integration planned as future expansion
