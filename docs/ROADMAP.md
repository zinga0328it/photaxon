# FiberSpider Roadmap

This document summarizes the research and development roadmap for the FiberSpider public laboratory.

## Current focus

- Stabilize the FiberSpider activation backend.
- Improve technician authorization and OTP workflows.
- Validate database persistence and deterministic resource state transitions.
- Build public documentation for the RAGNO laboratory branch.

## Near-term goals

- Expand cabinet simulation coverage for CAB-A, CAB-B, and CAB-C.
- Strengthen the integration between the activation API and persistent PostgreSQL state.
- Improve LLM-assisted topology proposal handling.
- Validate resource lease behavior and audit trail logging.

## Planned research directions

- physical ONT integration into the laboratory workflow.
- mini-OLT / GPON integration for closer hardware simulation.
- smart cabinet sensors for field telemetry and environmental awareness.
- distributed field cabinet prototype deployment.
- pilot deployment with research partners for real-world evaluation.

## Practical outcomes

- Demonstrate a distributed FTTH research laboratory with logical state and dynamic path modeling.
- Provide a foundation for future telecom research partnerships.
- Maintain a public proof-of-concept branch that documents architecture and research intent.
